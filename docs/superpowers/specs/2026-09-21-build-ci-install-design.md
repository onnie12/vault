## Goal

Onni has no Mac of his own. He can borrow or rent one, but a free Apple ID signature expires after 7 days, so he would need that Mac every week. Therefore GitHub's macOS runners do all compiling and testing, and a Mac is needed only to put the app on the phone.

## Project generation

- The Xcode project is generated by XcodeGen from `project.yml`, so it can be edited as text on Linux. The `.xcodeproj` is never committed.
- Generate in CI and on any Mac with `brew install xcodegen && xcodegen generate`.
- XcodeGen 2.46.0 works with Xcode 27 **[verified 2026-09-20 by CI run 35511865168]**. Its release notes never mention Xcode 27 (newest `objectVersion` it writes is 77), so re-check after XcodeGen or Xcode updates.
- **Fallback** if generation breaks: create the project once in Xcode 27 on the borrowed Mac and commit the `.xcodeproj` instead.

## CI

`.github/workflows/ci.yml` is the source of truth. Do not copy it into docs, copies go stale.

What it does, in order:

1. Runs on `xcode-27` (arm64, macOS 27, public preview). Label confirmed 2026-09-20.
2. Prints `sw_vers`, `xcodebuild -version`, `swift --version`.
3. Installs XcodeGen and generates the project.
4. `swift test --package-path VaultCore`.
5. Lists available simulators, then runs `xcodebuild test` on `iPhone 17`. If that simulator name does not exist on the runner, take one from the list step.
6. Builds Release for `iphoneos` with signing disabled, zips `Payload/Vault.app` into `Vault.ipa`, uploads it as the `Vault-ipa` artifact.

Action versions pinned on 2026-09-20: `actions/checkout@v7`, `actions/upload-artifact@v7`. Re-check the latest majors when touching the workflow.

The app repo `onnie12/vault` is **public** (CLAUDE.md section 14, question 1): macOS runner minutes on private repos are limited on the free plan, and the app code has no secrets. The document repo for GitHub sync must stay private.

## Install: borrowed or rented Mac (chosen route)

Onni chose this (CLAUDE.md section 14, question 7). A cloud Mac does not work: the iPhone must be connected by cable.

1. Install Xcode 27 (Apple silicon, macOS Tahoe 26.6 or later).
2. Xcode > Settings > Accounts > add Onni's Apple ID. This creates his Personal Team.
3. On the iPhone: Settings > Privacy & Security > Developer Mode > on, restart.
4. On the Mac: `git clone https://github.com/onnie12/vault.git && cd vault && brew install xcodegen && xcodegen generate && open Vault.xcodeproj`.
5. Connect the iPhone by cable, choose it as the run destination, select the Personal Team under Signing & Capabilities, press Run.
6. First launch: trust the developer in Settings > General > VPN & Device Management.
7. Repeat step 5 within 7 days to keep the app working. Reinstalling over the app keeps its data; deleting the app deletes it.

## Install: AltServer on Windows (not chosen, kept as fallback)

- AltServer 1.7.4 for Windows (2026-03-24) sideloads IPA files with a free Apple ID. Its notes mention a fix for iOS 26.4. **iOS 27 support is [unverified].**
- Flow: download `Vault.ipa` from the CI run, sideload with AltServer, re-sideload every 7 days. Free Apple IDs allow 3 active sideloaded apps.
- AltServer is a third-party tool that signs in with Onni's Apple ID. His decision, tell him plainly.
- Onni's daily machine is CachyOS Linux, so this route also needs a Windows PC.
